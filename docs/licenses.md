zfls is distributed under the MIT license, see [`LICENSE`](https://github.com/cesiumlang/zfls/blob/main/LICENSE), except for the ifx kit's startup code (`src/ifxkit/shim.zig`, `src/ifxkit/cxx.zig`), which is under MIT No Attribution (MIT-0) because it is linked into the programs built with the kit; the kit's import libraries come from MinGW-w64's public-domain definition files. ifx itself is Intel's, under Intel's license, which `zfls setup-ifx` shows and which the user accepts. zfls is derived from fortls and its predecessor fortran-language-server, also MIT licensed, whose copyright notices `LICENSE` includes. The intrinsic procedure documentation comes from the [M_intrinsics](https://github.com/urbanjost/M_intrinsics) project, also MIT licensed, whose notice `LICENSE` includes too: the `vendor/M_intrinsics` submodule, which a scheduled workflow moves to upstream latest commit. The Windows builds include the Win32 API bindings of [zigwin32](https://github.com/marlersoft/zigwin32), which rstd vendors, also MIT licensed, whose notice `LICENSE` includes as well.
